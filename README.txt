ГРУМИНГ — публикация для iPhone

Пакет подготовлен как PWA: index.html, manifest.json, service worker и иконки.
Для установки на экран Домой нужен HTTPS-хостинг (например, GitHub Pages).

Публикация через GitHub Pages:
1. На компьютере откройте github.com и войдите/создайте аккаунт.
2. Создайте новый публичный репозиторий, например grooming-booking.
3. Распакуйте grooming_pwa.zip.
4. Загрузите в корень репозитория все файлы и папку из grooming_pwa (index.html, manifest.json, sw.js, icon-192.png, icon-512.png).
5. В репозитории откройте Settings → Pages.
6. В разделе Build and deployment выберите Deploy from a branch, Branch: main, Folder: /(root), затем Save.
7. Подождите публикации; GitHub покажет адрес сайта вида https://ВАШ-ЛОГИН.github.io/grooming-booking/.

Установка на iPhone:
1. Откройте полученную HTTPS-ссылку именно в Safari.
2. Нажмите Поделиться (квадрат со стрелкой вверх).
3. Выберите «На экран Домой» / Add to Home Screen.
4. Название «Груминг» → Добавить.
5. Запускайте приложение с новой иконки.

Данные записей остаются локально в браузере этого iPhone. Не очищайте данные Safari и периодически используйте встроенное резервное копирование. Размещение сайта не синхронизирует записи между устройствами.
