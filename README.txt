ГРУМИНГ — приложение для записи клиентов

Публикация: загрузите содержимое этой папки в корень GitHub-репозитория и включите GitHub Pages (ветка main, папка /root).

Календарь: в форме записи нажмите «Добавить в календарь» либо в разделе быстрых действий — «Экспорт календаря». Файл .ics содержит два сигнала: за сутки и за час. На iPhone откройте файл и добавьте событие в Календарь.

Уведомления: кнопка «Включить уведомления» запрашивает разрешение браузера. Напоминания приложения срабатывают, пока страница открыта/работает. Это не серверный Web Push: для гарантированных push-уведомлений, когда приложение закрыто, требуется серверная часть с Web Push и планировщиком. Поэтому для надёжных сигналов используйте также события Календаря iPhone.

Данные записей хранятся локально в браузере на устройстве. Очистка данных сайта может удалить записи; регулярно используйте «Резервная копия».
